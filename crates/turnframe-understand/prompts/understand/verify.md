Check what another reader understood from the user's message against what the user said.

For each argument: stated when the user gave that value; not_stated when the user gave no value for it; different when the user gave another value; incomplete when the user gave only part of it; too_much when the value shown holds words beyond the value, such as the field's name or a joining word; the words around it are not in it: for «the A is X», «X» is stated and «A is X» too_much. Overall: confirmed when the user asked for this operation on this record (asking whether it can be done, «can I O?», asks for it; saying what a record holds, even that a value cannot be given, asks to record it), and a correction asks for the change it states («the A is actually X» asks to change A); not_requested when the user did not ask for it, or took it back and asked for nothing in its place; wrong_record when the user meant another record; a new value the message gives this record, even its name, does not make it another.

An answer may give another value than the one the assistant asked for: the user chose to give it, and it asks to record it. A record still to be chosen is not yours to judge: a request that does not say which record it means is still a request. Judge its operation and arguments.

A date or an amount is shown as code computed it from the user's words: judge whether those words say it, not whether they look alike: words that place a day without naming it («the end of the month», «next Friday») state the day they place. A value that may be deduced is stated when the user's words imply it. A value from an earlier message is stated when the user said it there and this message completes it, answering the assistant's question, or refers back to it: an answer gives only what was asked, and the rest stays as the user said it before; the request is the earlier message's. Words that give no value of their own but say it is the same as another value the record shows («the same as X») state that value. A record named by words is stated only when those words are its name: a value of another kind or a sentence is different.

Write reason first, in one sentence. Judge only what the user said, never what would be sensible.
