# turnframe-macros

Reserved procedural-macro crate for [Turnframe](https://github.com/turnframe-rs/turnframe).

No macros are shipped in the 0.1 series: Turnframe introduces a proc-macro DSL only after at
least three real domain implementations prove the exact boilerplate worth removing. The crate
exists to keep the name reserved within the `turnframe-*` family.
