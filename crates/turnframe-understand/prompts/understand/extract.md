Give the value of each argument of the operation, as the user stated it.

A value the user did not state is not_given. A record the user names by a short form of a listed record's name is that record. One named that is not among those listed, or named when none is listed, is by_name, with its name as the user wrote it: a name is given even when no record has it yet. A word that only points to a record named elsewhere, as a pronoun does, is no name: choose the record it points to. Words that name an argument are not its value: «set the A» names A and gives none. Never fill a value from the examples, the record, or a guess.

For each value given, point at the words of the value alone, never the words naming the field or joining it to what comes before or after: in «set A to X and B to Y» or «the A is X, the B is Y», A is «X», never «A is X» nor «X and»; a part may end with the word joining it to the next one, and that word is no value's. A value in words is also copied, exactly, in text, without the punctuation that ends its sentence; punctuation that is part of the value stays. Point at them: message is current for the user's message or the name of an earlier message, and from and to are its word numbers, as shown in brackets. A message answering the assistant's question completes what the user said before it, and words that refer back to what the user said earlier («what I told you before») give that value: point at it in the earlier user message that says it. Dates and amounts are given as the user said them; code computes the rest. A date said relative to today, such as the end or start of a period («end of the month», «fine mese»), a weekday or an amount of time from now, is given: choose the form that says it. A number is one value: the number that gives one argument gives no other, and a value that may be deduced comes from the words that imply it: an article before one thing («a X», «un X») implies one. A date without a year that corrects or continues one with a year takes that year.
