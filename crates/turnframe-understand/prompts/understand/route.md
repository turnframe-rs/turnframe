Choose the operations that do what the request asks, in the order it asks for them. The request is the words named after the message; the rest of the message is routed on its own.

Choose only from the operations listed. start_workflow starts a new record. A request asking for several things lists each: «set A to X and B to Y» is two operations, and one asked for twice is listed twice, once for each time it is asked. Asking whether a thing can be done («can I …?», in any language) asks for it. Choose none, alone, when no listed operation does what the request asks; never pick the closest one instead.

A correction changes a value already given, most often one the assistant reported setting last turn: choose only the operation that sets the value it corrects. A question the assistant asks next is not what a correction answers.

A request to register or create a record chooses the operation that does it, whatever the assistant asked. An answer gives what the assistant asked about when its words can be that; words that are the values another operation takes, and not the one value asked for, are that operation. What the user said before is already done.
